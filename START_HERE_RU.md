# Начни отсюда

1. Распакуй архив `video-re-editor` на компьютере.
2. Создай бота через Telegram `@BotFather` → `/newbot` и скопируй токен.
3. Скопируй `.env.example` в `.env`, вставь токен в `BOT_TOKEN=`. Другие настройки пока не меняй.
4. Не добавляй `.env` в GitHub.
5. Для загрузки исходников создай Private-репозиторий: https://github.com/new и используй GitHub Desktop.
6. Установи Python 3.12+ и FFmpeg, затем запусти `run_windows.bat`.
7. Открой бота в Telegram, нажми `/start` и отправь тестовый MP4 до 19 MB.
8. Для аудита проекта в Claude Code открой `CLAUDE_TASK_RU.md` и отправь его содержимое. Вначале попроси только аудит, без изменений файлов.

Полная инструкция, лимиты, хостинг и диагностика — в `README_RU.md`.
