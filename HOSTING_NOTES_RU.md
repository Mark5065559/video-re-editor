# Где запускать бота бесплатно

## Коротко

| Вариант | Цена | 24/7 | Сложность | Для FFmpeg |
|---|---|---|---|---|
| Свой Windows-компьютер (`run_windows.bat`) | бесплатно | пока ПК включён | очень просто | зависит от ПК, обычно хорошо |
| Oracle Cloud Always Free (Ampere A1 + Docker) | бесплатно* | да | средне | хорошо (ARM, много памяти) |
| Google Cloud e2-micro | бесплатно* | да | средне | слабо: 1 ГБ памяти, мало бесплатного трафика |
| Render / Koyeb free | бесплатно | засыпают | просто | слишком слабые, диск временный |
| GitHub / Codespaces / Actions | — | нет | — | GitHub хранит код, но не запускает бота постоянно |

\* Условия бесплатных тарифов меняются. Перед созданием ресурса проверь метку **Always Free** / **Free tier** и не включай платные ресурсы, автопополнение и платные API.

**Рекомендация:** сначала запусти бота на своём компьютере и проверь на своих роликах. Если нужен круглосуточный бот — перенеси на Oracle Always Free.

## Oracle Cloud Always Free: пошагово

На момент проверки официальная страница Always Free указывает для Ampere A1 3000 OCPU-часов и 18 000 ГБ-часов памяти в месяц (4 ядра и 24 ГБ). Встречаются сообщения, что в 2026 году лимит уменьшили, — смотри актуальные цифры на https://docs.oracle.com/en-us/iaas/Content/FreeTier/resourceref.htm и в своей консоли.

Важно знать заранее:
- при регистрации просят банковскую карту для проверки личности; с Always Free-ресурсов деньги не списываются;
- в популярных регионах свободных машин A1 иногда нет («Out of capacity») — пробуй позже или выбери меньший размер;
- Oracle может остановить машину, которая 7 дней почти не загружена (CPU, сеть, память). Данные на диске остаются, машину запускают снова кнопкой Start в консоли.

### 1. Создай сервер

1. Зарегистрируйся: https://www.oracle.com/cloud/free/
2. Консоль → **Compute → Instances → Create instance**.
3. Image: **Canonical Ubuntu 24.04** (или 22.04). Shape: **Ampere → VM.Standard.A1.Flex**, например 2 OCPU и 12 ГБ памяти. Убедись, что рядом стоит метка **Always Free-eligible**.
4. В разделе SSH keys нажми **Save private key** — сохрани файл ключа (например, `oracle.key`).
5. **Create**. Когда машина запустится, скопируй её **Public IP address**.

Входящие порты открывать не нужно: бот сам обращается к Telegram (long polling).

### 2. Подключись по SSH (Windows 10/11 — PowerShell)

```powershell
ssh -i C:\путь\к\oracle.key ubuntu@ПУБЛИЧНЫЙ_IP
```

Если Windows ругается на права ключа, положи его в папку `C:\Users\ТВОЁ_ИМЯ\.ssh\`.

### 3. Установи Docker

```bash
sudo apt update && sudo apt install -y unzip
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
exit
```

Подключись по SSH ещё раз, чтобы права применились.

### 4. Перенеси проект

Репозиторий приватный, поэтому проще загрузить архив. На своём компьютере скачай ZIP с GitHub (**Code → Download ZIP**) и отправь на сервер:

```powershell
scp -i C:\путь\к\oracle.key C:\Users\ТВОЁ_ИМЯ\Downloads\video-re-editor-main.zip ubuntu@ПУБЛИЧНЫЙ_IP:~
```

На сервере:

```bash
unzip video-re-editor-main.zip
cd video-re-editor-main
cp .env.example .env
nano .env
```

Впиши `BOT_TOKEN`, `TG_API_ID`, `TG_API_HASH`, `ALLOWED_USER_IDS`, сохрани (`Ctrl+O`, `Enter`, `Ctrl+X`).

### 5. Запусти

```bash
docker compose up -d --build
docker compose logs -f
```

Когда в логах появится «Бот запущен», выйди из просмотра логов (`Ctrl+C`) — бот продолжит работать. Он сам перезапускается после сбоев и перезагрузки сервера.

Важно: **один токен — одна запущенная копия.** Если бот работает на сервере, закрой его на домашнем компьютере, иначе будет ошибка `Conflict: terminated by other getUpdates request`.

### Обновление

Загрузи новый ZIP, распакуй поверх (файл `.env` не трогай) и выполни `docker compose up -d --build`.

## Почему не Render, Koyeb, Hugging Face и т.п.

Бесплатные веб-инстансы таких сервисов обычно засыпают без входящих HTTP-запросов, имеют долю ядра и 512 МБ памяти, а файловая система у них временная. Для бота, который скачивает и перекодирует видео по 50–300 МБ, это ненадёжно. Некоторые сервисы ограничивают доступ к Telegram или запрещают постоянные фоновые процессы в условиях использования.

## GitHub не запускает бота

GitHub — это хранилище кода. GitHub Codespaces — среда разработки с месячной квотой, а GitHub Actions предназначены для сборки и тестов проекта; ни то ни другое не подходит для постоянно работающего бота.

## Как не потратить деньги

- Не включай Pay-as-you-go, автопополнение и платные ресурсы, пока не понимаешь лимиты.
- Бот не использует платные API: FFmpeg, aiogram, Telethon и SQLite бесплатны и работают локально.
- Если где-то отображается остаток вроде «$13», это может быть промо-кредит облака, кредит API или лимит другого сервиса — они не взаимозаменяемы. Посмотри название сервиса на странице, где виден остаток, и не вводи платёжные данные ради этого проекта.
