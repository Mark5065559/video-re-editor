# Бесплатный сервер 24/7: Oracle Cloud + установщик в один файл

Бот работает на бесплатном сервере Oracle круглосуточно — ноутбук можно выключать, пользоваться ботом с телефона. Всё настраивает один файл-установщик: в нём уже вписаны токен бота и ключи Telegram, поэтому ничего вводить не нужно.

Установщик сам ставит FFmpeg и Python, скачивает код бота с GitHub, включает автозапуск (после сбоя или перезагрузки бот поднимается сам) и раз в 6 часов проверяет обновления. Новая версия ставится только если прошла проверку, а если не запустилась — возвращается прежняя.

## Что нужно сделать тебе (около 20 минут, один раз)

### 0. Репозиторий на GitHub — публичный

Сервер скачивает код с GitHub, поэтому репозиторий должен быть публичным. Токена и ключей в нём нет — они только в файле-установщике.

1. Открой https://github.com/Mark5065559/video-re-editor/settings
2. Прокрути в самый низ до **Danger Zone** → **Change repository visibility** → **Change visibility** → **Change to public**.
3. Подтверди (GitHub попросит нажать кнопки подтверждения и, возможно, ввести пароль или код).

### 1. Регистрация в Oracle Cloud

1. Открой https://signup.cloud.oracle.com/
2. Страна, имя, email → подтверди почту → придумай пароль и имя аккаунта (латиницей, любое).
3. **Home Region** — выбери ближайший к себе. Поменять его потом нельзя.
4. Адрес, телефон и банковская карта (Visa/Mastercard). Карта нужна только для проверки: Oracle может временно заблокировать около 1 $ и вернёт его. За Always Free-ресурсы деньги не списываются.
5. Дождись письма, что аккаунт готов (обычно несколько минут, иногда дольше).

### 2. Создание сервера с установщиком

1. Войди в консоль https://cloud.oracle.com → меню ☰ → **Compute** → **Instances** → **Create instance**.
2. **Name** — любое, например `video-bot`.
3. **Image and shape**:
   - **Image** → **Change image** → **Ubuntu** → **Canonical Ubuntu 24.04** → **Select image**.
   - **Shape** → **Change shape** → **Ampere** → **VM.Standard.A1.Flex**, 2 OCPU и 12 GB памяти (рядом должна быть метка **Always Free-eligible**) → **Select shape**.
   - Если пишет **Out of capacity** (нет свободных машин): выбери другую Availability Domain, уменьши до 1 OCPU / 6 GB или возьми **Specialty and previous generation → VM.Standard.E2.1.Micro** (тоже Always Free; видео будет обрабатываться медленнее, установщик сам добавит файл подкачки).
4. **Networking** — ничего не меняй (новая сеть и публичный IP-адрес по умолчанию нужны, чтобы бот выходил в интернет).
5. **SSH keys** — оставь «Generate a key pair for me». Ключ можно сохранить (**Save private key**), но для бота он не нужен.
6. Внизу **Show advanced options** (или **Advanced options**) → вкладка **Management** → **Initialization script** → **Choose cloud-init script file** → выбери файл `video-re-editor-oracle-install.sh`. Можно вместо этого выбрать **Paste cloud-init script** и вставить весь текст файла.
7. **Create**.

### 3. Готово

Подожди 10–15 минут после создания сервера, открой своего бота в Telegram и нажми `/start`. Первый, кто напишет боту, становится его **владельцем** — бот ответит «👑 Ты — владелец этого бота». Остальные люди увидят «частный бот». Поэтому напиши боту первым.

## Важно знать

- **Один токен — одна копия бота.** Пока бот работает на сервере, не запускай его на ноутбуке, иначе будет ошибка `Conflict: terminated by other getUpdates request`.
- Файл-установщик содержит токен и ключи — никому его не пересылай. Если он попал в чужие руки: в `@BotFather` команда `/revoke`, затем создай новый установщик с новым токеном и пересоздай сервер.
- Oracle может остановить машину, которая долго почти ничего не делает (простаивает). Тогда в консоли: **Compute → Instances →** твой сервер → **Start**. Бот запустится сам.
- Условия бесплатного тарифа могут меняться. Не включай Pay-as-you-go и платные ресурсы. Актуальные лимиты Always Free: https://docs.oracle.com/en-us/iaas/Content/FreeTier/resourceref.htm

## Если бот не отвечает через 20 минут

1. Проверь, что репозиторий публичный (шаг 0) — установщик ждёт его и повторяет попытки каждые 2 минуты.
2. В консоли Oracle открой свой сервер → **Resources** (или вкладка **OS management / Console**) → **Console history** → **Capture console history** → открой результат. Строки, начинающиеся с `[video-re-editor]`, показывают, на каком шаге установка. Пришли их Claude.
3. Для тех, кто подключается по SSH: `sudo video-re-editor-status` — состояние и последние строки журнала бота; ход установки — `sudo tail -n 50 /var/log/video-re-editor-install.log`.

## Как сделать установщик заново (например, с новым токеном)

На своём компьютере в папке проекта:

```bash
python deploy/oracle/build_installer.py --out video-re-editor-oracle-install.sh
```

Скрипт берёт `BOT_TOKEN`, `TG_API_ID`, `TG_API_HASH` из `.env` (или из параметров `--token`, `--api-id`, `--api-hash`). Готовый файл в Git не попадает (он в `.gitignore`).

## Другие варианты

| Вариант | Цена | 24/7 | Комментарий |
|---|---|---|---|
| Oracle Cloud Always Free + установщик | бесплатно | да | рекомендуемый вариант, описан выше |
| Свой компьютер (`run_windows.bat`) | бесплатно | пока ПК включён | самый простой для проверки |
| Свой Linux-сервер + Docker | — | да | `docker compose up -d --build`, см. README |
| Hugging Face Spaces | бесплатно | — | доступ к Telegram API оттуда заблокирован, бот работать не будет |
| Render / Koyeb free | бесплатно | засыпают | слишком слабые для FFmpeg, временный диск |
| GitHub / Codespaces / Actions | — | нет | GitHub хранит код, но не запускает бота постоянно |

## Как не потратить деньги

- Не включай Pay-as-you-go, автопополнение и платные ресурсы, пока не понимаешь лимиты.
- Бот не использует платные API: FFmpeg, aiogram, Telethon и SQLite бесплатны и работают на самом сервере.
