# Где запускать бота и что означает «$13 осталось»

## Рекомендуемая схема

**На первом этапе:** GitHub Private хранит исходный код, а бот работает на твоём Windows-компьютере через Python/FFmpeg или Docker. Это не требует ежемесячной оплаты хостинга, но компьютер должен быть включён и подключён к интернету.

**Позже:** можно перенести бота на собственную Linux VM, если найдётся бесплатный always-free ресурс и ты сможешь пройти его регистрацию и настройку. Бесплатность VM не означает неограниченную производительность, место на диске или передачу данных.

## GitHub не является сервером для 24/7

GitHub — это репозиторий кода. GitHub Codespaces — облачная среда разработки, но не рассчитана на то, чтобы держать постоянно работающий процесс бота. У личного GitHub Free есть месячная квота Codespaces (120 core-hours и 15 GB-month storage по опубликованной таблице). Когда квота исчерпана, доступ к дальнейшему платному использованию блокируется без способа оплаты либо может тарифицироваться при включённой оплате/бюджете. Смотри актуальные условия: https://docs.github.com/en/billing/concepts/product-billing/github-codespaces.

## Почему Render Free не выбран

Render Free Web Service усыпляется после 15 минут без входящего HTTP-запроса; файловая система эфемерная, поэтому временные файлы и локальная SQLite-база могут исчезнуть при перезапуске/засыпании. Для бота, которому нужно загружать и обрабатывать видео, это ненадёжный вариант. Официально: https://render.com/docs/free.

## Oracle Cloud Always Free

Oracle публикует Always Free вычислительные ресурсы, в том числе Ampere A1, с месячными бесплатными объёмами CPU/RAM. Но доступность свободных машин зависит от региона и наличия ёмкости; при нехватке capacity создать VM может не получиться. Пробные рекламные кредиты и Always Free — разные вещи. Проверяй метку Always Free перед созданием ресурсов и не включай платные ресурсы: https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm.

## Что могут означать твои $13

По одной фразе невозможно определить сервис. Это может быть промо-баланс облака, prepaid API credits или иной внутренний лимит. Эти вещи не взаимозаменяемы:

- GitHub Codespaces у личного бесплатного аккаунта показывает квоту в часах и хранилище, а не обычный баланс «$100».
- Claude Code при входе через аккаунт Claude использует лимиты подписки/сессий; при входе через API key расходы идут по API-тарификации. В Claude Code команда `/cost` показывает стоимость текущей API-сессии, а `/status` — состояние использования плана. Автопополнение API-кредита настраивается отдельно.
- Облачные провайдеры могут выдавать промо-кредиты на ограниченный срок и конкретный набор ресурсов. Их нельзя считать гарантией бесплатного запуска после окончания промо.

Пока не создавай платные ресурсы и не соглашайся на автоматическое пополнение. Для выяснения происхождения $13 открой страницу, где отображается остаток, и посмотри название сервиса и тип баланса. Для проверки достаточно скриншота, где скрыты имя, адрес, ID аккаунта, платёжные данные и ключи.
